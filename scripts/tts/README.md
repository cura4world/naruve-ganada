# scripts/tts — Typecast 청취 샘플 생성

DECISIONS.md 9절(음성 자산)의 TTS 벤더 선정을 위해, 후보 보이스에 같은 문장을
읽히고 나란히 듣게 만드는 하네스다. **품질 판단은 사람이 한다.** 이 스크립트는
같은 조건으로 파일을 만들고 무엇을 얼마에 만들었는지 기록만 남긴다.

`docs/`·`worker/`와 무관하다. 앱에 실리지 않으므로 빌드번호를 올리지 않는다.

## 파일

| 파일 | 역할 |
|---|---|
| `typecast_gen.py` | 생성기. 문장 × 보이스를 돌며 `{폴더}/{sentence_id}.mp3`를 만든다 |
| `config.json` | 모델·언어·포맷·동시성. **언어와 모델이 코드에 박혀 있지 않다** |
| `voices.json` | 후보 보이스 목록. 선정이 끝나면 채택된 2개만 남긴다 |
| `sentences.json` | 문장 13개. 10개는 `docs/js/data.js`에서, 3개는 08-18 Azure 비교 대조용 |

파이썬 파일에 한국어도 특정 보이스도 없다. 다른 언어로 갈 때는 `config.json`의
`language`를 바꾸고 `voices.json`·`sentences.json`을 그 언어 것으로 갈아끼우면 된다.
껍데기는 그대로 쓴다.

## 준비

```
python -m pip install --upgrade typecast-python
```

공식 Python SDK다. 문서 권고에 따라 REST를 직접 짜지 않았다.
`ffprobe`가 PATH에 있으면 총 재생 길이를 재서 단가를 계산한다. 없으면 그 줄만 빈다.

키는 저장소 루트 `.env`의 `TYPECAST_KEY`다. 스크립트는 이 순서로 찾는다.

1. 환경변수 `TYPECAST_KEY`
2. 환경변수 `TYPECAST_API_KEY` (SDK 기본 이름)
3. 저장소 루트 `.env`

어느 경로로도 키를 찍거나 산출물에 남기지 않는다. `.env`는 `.gitignore`에 있다
(`.gitignore:8`). 확인: `git check-ignore -v .env`

## 실행

```
# 계획만 본다. 호출하지 않는다
python scripts/tts/typecast_gen.py --out "D:/aihub_work/tts_typecast_candidates_20260819" --dry-run

# 실제 생성
python scripts/tts/typecast_gen.py --out "D:/aihub_work/tts_typecast_candidates_20260819"

# 호출 없이 index.html·README.md·zip만 다시 만든다
python scripts/tts/typecast_gen.py --out "..." --reindex
```

| 옵션 | 뜻 |
|---|---|
| `--out` | 출력 폴더 (필수) |
| `--sentences` `--voices` `--config` | 입력 파일 경로 (기본은 이 폴더) |
| `--jobs N` | 동시 호출 수. config를 덮어쓴다 |
| `--dry-run` | 호출하지 않고 남은 칸만 센다 |
| `--reindex` | 호출 없이 문서만 다시 만든다 |
| `--no-index` `--no-zip` | 문서·zip을 만들지 않는다 |

산출물은 `{성별}_{이름}_{voice_id 뒤 6자리}/{sentence_id}.mp3` 그리고
`index.html`(행=문장, 열=보이스 비교표) · `README.md` · `manifest.json` ·
`sentences.json` · `voices.json` · 상위 폴더의 `.zip`이다.

## 안전장치

- **재실행 안전.** 이미 있고 크기가 0이 아닌 파일은 건너뛴다. 다시 돌려도 크레딧이 안 나간다
- 받는 중에는 `.part`로 쓰고 다 받으면 rename 한다. 중간에 끊겨도 반쪽 파일이 완성본으로 남지 않는다
- **동시 호출은 5를 넘지 않는다.** config가 더 큰 값을 줘도, 구독 응답의 `concurrency_limit`과
  코드 상수 둘 다로 조인다. 라이트 플랜 한도가 5다
- 429·5xx는 지수 백오프로 재시도한다. 402(크레딧 부족)와 4xx는 즉시 멈춘다 — 재시도해도 같다
- 시작 전에 잔량이 상한 추정보다 적으면 아예 시작하지 않는다. 156칸을 반쯤 만들다 끊기는 것을 막는다
- 시작 전에 보이스 ID가 그 모델 카탈로그에 있는지 확인한다
- 보이스 폴더명이 겹치면 시작하지 않는다 (덮어쓰기 방지)

## 크레딧 계산법

**과금은 글자수가 아니라 오디오 길이 기준이다.** Typecast 문서에 이 규칙이 없어서
2026-08-19 실행에서 실측했다.

| 실측값 | |
|---|---|
| 실제 차감 | 970 |
| 총 재생 길이 (ffprobe) | 323.8초 |
| 초당 | **약 3.0 크레딧** |
| 글자당 환산 | 약 0.48 (168자 × 12보이스 = 2,016자에 970) |

길이 기준이라는 근거: 12개 보이스에 넣은 텍스트가 완전히 같은데 총 차감 970이
12로 나눠떨어지지 않는다. 텍스트 기반이면 보이스마다 값이 같아야 하므로
나눠떨어져야 한다. 길이 × 3 = 971.4로 실제 970과 0.1% 차이다.

`config.json`의 `credits_per_char: 1`은 **실행 전 잔량 확인용 상한**이다.
실제보다 두 배 넘게 비싸게 잡지만, 넉넉해야 중간에 402로 끊기지 않는다.
실제 차감은 매 실행마다 실행 전후 구독 조회로 실측해 `manifest.json`에 남는다.

문장 1000개를 보이스 하나로 읽히면 이 문장들의 평균(2.08초)으로 약 6,200 크레딧이다.
라이트 플랜 200,000 안에 넉넉히 들어간다. 다만 이 평균은 38자짜리 `s08`이 섞인
값이라 실제 문장 분포와 다를 수 있다 — 추정이다.

## 주의 — 구독 기간 안에 다운로드를 마쳐야 한다

라이트 플랜 출력물은 상업 이용이 가능하다. **단 구독 기간 안에 다운로드를 끝내야
그 권리가 남는다** (Typecast 고객센터 회신 2026-08-19).

그래서 이 스크립트는 스트리밍하지 않고 생성 즉시 로컬 파일로 떨어뜨린다.
받아둔 폴더를 지우면 다시 만들어야 하고, 구독이 끝난 뒤에는 다시 만들 수 없다.

## 앱에 넣을 때

여기서 만든 파일은 아직 앱에 들어가지 않는다. 선정이 끝나 2개를 고르면
CLAUDE.md "예시 음성" 절대로 `docs/audio/`에 mp3를 넣고 `index.json`에 파일명을
적는다. 그때 `audio.js`는 고치지 않는다 — 파일이 있는 문장만 1번 경로가 이긴다.
파일명은 한국어 문장의 해시다.
